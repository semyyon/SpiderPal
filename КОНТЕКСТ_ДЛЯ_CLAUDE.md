# Контекст: Паучок на паутине (Песочница, 05.11.2026)

Развлекательная настольная игрушка для Windows. Папка: `C:\Работа\Песочница\Спайдермен\`.
Файлы: `spider.py` (логика, окна, трей, самотест), `art.py` (вся рисовка, скелет, позы, шапки),
`gallery.py` (галереи PNG), `SpiderPal.exe` (PyInstaller onefile), `run.bat`, `phrases.txt`, `.venv` (PySide6-Essentials 6.12,
pyinstaller), `скриншоты\` (самотесты, галереи), `README.md` — полное описание поведения и замеров.

## Решения пользователя (закон)
- Персонаж — фан-арт, рисуется кодом; только чиби (~64 px). Человеческое телосложение УБРАНО по просьбе (05.11).
- В пределах одного монитора паук ТОЛЬКО ползает (плавно, ≤420 px/с, без телепортов); махи на паутине — только на другой монитор.
- Ползание — вид со спины (голова вперёд, лица нет); у спины свой крой костюма.
- Трюки в полёте — по очереди, каждый пролёт другой; позы махов тоже чередуются.
- Мем: 10 минут простоя (05.11, поздняя правка); треугольник; средний разводит руки (левой на левого, правой на правого), левый — вытянутая
  + согнутая у пояса, правый — спиной, одна рука вытянута, вторая почти не видна; спускаются сверху на паутинах.
- Простой: 3 с — сесть на кромку активного окна; 5 с сон; 10 мин мем. КОКОН УБРАН (05.11).
- Сон и сидение (для всех костюмов) НЕ прерывает движение мыши: только левый клик по самому пауку (Buddy.wake/hit_hero) или закрытие/сворачивание его окна (window_rect). Клик проходит и в приложение под ним (принято).
- Весь интерфейс (меню, реплики, названия) — английский; исключение — строки песни Нуара (song.txt, русские, пользователь вписывает сам; текст песни в код НЕ вписывать — авторское право).
- Головокружение: 8 взмахов за 1,5 с, пик >2500 px/с.
- Spider-Noir (костюм noir): маска до носа, щетина, федора, сигарета+дым (art.draw_smoke), ползёт 150 px/с, не спит — садится на окно или посреди экрана; через 15 с сидения прилетает гитарист (Buddy.band, art.draw_guitar, поза guitar), раз в 4–6 мин; кашляет, ворчит (NOIR_JOKES). Тест: --selftest DIR --noir.
- Мем: спиной стоящий (жёлтый) ниже остальных, вторая рука опущена; указующие руки смотрят на соседа.
- Туловище и ноги — один силуэт: контур торса обрезан по талии (art.draw_torso, setClipRect).
- Сон (05.11, переопределено): улетает к боковой кромке активного окна (или края экрана), спит вниз головой на паутине, обе руки держат её, ноги согнуты (поза со скриншота-образца пользователя). Реализация: Buddy.roost, plan_roost.
- Руки не обводятся отдельно на стыке: корень закрыт перерисовкой торса/головы (art.draw_spider.cover).
- Анатомия: конечности по профилю мышц (art.PROFILES), ноги рисуются ДО торса (растут из-под таза).
- Ползание (05.11, переопределено): левая рука вперёд (вытянута) + левая нога прямая, правая рука и нога согнуты, потом наоборот; фаза по пройденному пути; IK по целям art.crawl_targets; 300 px/с.
- Ночь 18:00–08:00 (пижама, колпак, быстрее засыпает); утро 08:00–12:00 — с чашкой кофе; весь декабрь — новогодний.
- Двойник — только по Ctrl+C (06.11; в висе и сидя, нажатие помнится 3 с; five / pillow по очереди, спуск DESCENT 2,4 с);
  реплики по событиям + шутка раз в 10–15 мин.
- 06.11: клик-выстрел — левая рука указывает на точку 0,8 с (Buddy.aim_arm, AIM_TIME), нить из её ладони; сон — ноги

  Ctrl+S не показывал палец, а двойник — ладонь при 120 к/с.

## Устройство
- Оверлей: по окну на каждый экран, WA_TranslucentBackground + WindowTransparentForInput + Tool + TopMost, высота −1 px.
- Перерисовка только грязных прямоугольников; голова и торс кэшируются в QPixmap (art._cached), мем — кэш неподвижной части.
- Скелет: art.STYLES (только chibi), позы — углы суставов (art.POSES, 0° вниз, + наружу), art.fk() -> точки.
- Режимы героя: hang, crawl, sit, swing, air (см. docstring Buddy). Окна — foreground_window() через Win32/DWM.
- Самотест подменяет курсор и foreground_window (имитация окна), реальную мышь/окна не трогает.

## Уроки
- Снимок экрана (QScreen.grabWindow) захватывает и чат Claude, и запущенную копию паука — перед тестом гасить SpiderPal.exe.
- Реальные клики пользователя во время теста создают паутинки и поднимают FPS/CPU — учитывать при чтении замеров.
- Многострочные замены PowerShell ломаются на CRLF — нормализовать `\r\n` -> `\n`.

## Открытые вопросы / идеи
- CPU в игре двойника ~5 %, в меме с кликами ~7,7 % — можно снизить (кэш тел двойника, 60 к/с для паутинок).
- Перевод координат окон при смешанном DPI приблизительный (делим на DPR основного экрана).
